🚀 Acerca del Proyecto
Este proyecto combina el diseño de interfaces moderno realizado en Figma con el desarrollo de componentes reutilizables utilizando React. La plataforma busca ofrecer una experiencia fluida para la gestión y visualización de contenido relacionado con el mundial.

🛠️ Stack Tecnológico
Frontend: React.js

Diseño UI: Figma

Entorno de desarrollo: CodeSandbox
